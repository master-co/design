```sh
bun run build
bun run check
bun run test:install
bun run test:typography
bun run test:reading
```

The [reading section](../../examples/interface-craft/typography-layout/README.md#reading-controls) is part of `typography-layout.html`. It uses existing fixed language samples and pinned font shards. No new dependency, font download or external runtime source is required. The existing workspace and six exported typography/layout diagrams retain their inputs.

The new script verifies 120 combinations across Chromium and WebKit: five language samples × three widths × two themes × two text scales × two engines. It measures actual anchor bounds and hit-tests their extension above/below the text; checks a separate arrow column and first-line center; tests keyboard navigation, direct first-touch copy and clipboard failure in ten locale/engine combinations; and checks reduced motion plus no-JavaScript anchor/code fallback.
