# Sources and ownership

The immediate first-party basis is the interface-craft article candidate at `1aron/aron.tw`, commit `4733743`, including 35 original diagrams and two local interaction studies. Its ideas were developed through measured comparisons, native raster checks and author preferences. The full article and illustration history remain in that repository.

The original workspace data, chart geometry and component drawing code are copied into this repo as first-party example source. The standalone study uses no third-party UI kit or brand case study. Font assets retain the bundled Geist and IBM Plex Mono OFL notices.

## Research references

- [Agent Skills specification](https://agentskills.io/specification): package format and progressive disclosure.
- [Skills installer documentation](https://github.com/vercel-labs/skills): discovery and local project installation.
- [Jakub Krehel's skills](https://github.com/jakubkrehel/skills/tree/592aedc44d7d5b3e29740984252902f3e5402a1c/skills): research entry points for interface explanation, image finishing, type and surface craft. This repo does not copy that instruction set or treat its fixed values as universal requirements.
- [Bornblessed ring/hairline demonstration](https://x.com/bornblessed___/status/2087138994526020067): historical research recorded in the article materials. The observed 1px/12% to .5px/18% comparison separates contour width from opacity; it is not a universal conversion rule.
- [CSS Text](https://drafts.csswg.org/css-text-4/), [CSS Fonts](https://drafts.csswg.org/css-fonts-4/), [CSS Inline Layout](https://drafts.csswg.org/css-inline-3/) and [CSS UI](https://drafts.csswg.org/css-ui-4/): mechanism references; draft status is distinct from actual browser support.

Measured, derived and judged findings stay separate. Browser checks record their actual engines, device densities and tested conditions. A CSS support query is not a replacement for observed rendering.

Aron preferences are explicitly selected taste, with contextual starting values. They are not a new historical movement, a replacement for project branding, or a requirement to install the original article's fonts.

## Avatar-stack research — 2026-10-30

- [Fluent Avatar group usage](https://fluent2.microsoft.design/components/web/react/core/avatargroup/usage): identifies the stack as the condensed overlapping configuration of an avatar group. Its own overflow threshold is a system choice, not the four-slot specimen used here.
- [Primer AvatarStack](https://primer.style/product/components/avatar-stack/): documents a space-constrained inline stack and distinguishes its variants. Its API, hover spread and example assets are not copied into this implementation.

The new rules, diagrams, code and fictional portraits are original. Surface separation, image inset and geometry are explicitly distinct. The D32/O8/G2 study, four-slot capacity and D22 dashboard treatment are author-selected specimens. Image generation prompts and original/derived hashes are preserved in `assets/avatars/`; no model version is invented. Browser measurements, derived extents and visual judgments remain separate.
