# Sources and ownership

The immediate first-party basis is the interface-craft article candidate at `1aron/aron.tw`, commit `4733743`, including 35 original diagrams and two local interaction studies. Its ideas were developed through measured comparisons, native raster checks and author preferences. The full article and illustration history remain in that repository.

The original workspace data, chart geometry and component drawing code are copied into this repo as first-party example source. The standalone study uses no third-party UI kit or brand case study. Font assets retain the bundled Geist and IBM Plex Mono OFL notices.

## Research references

- [Agent Skills specification](https://agentskills.io/specification): package format and progressive disclosure.
- [Skills installer documentation](https://github.com/vercel-labs/skills): discovery and local project installation.
- [Jakub Krehel's skills](https://github.com/jakubkrehel/skills/tree/592aedc44d7d5b3e29740984252902f3e5402a1c/skills): research entry points for interface explanation, image finishing, type and surface craft. This repo does not copy that instruction set or treat its fixed values as universal requirements.
- [Bornblessed ring/hairline demonstration](https://x.com/bornblessed___/status/2087138994526020067): historical research recorded in the article materials. The observed 1px/12% to .5px/18% comparison separates contour width from opacity; it is not a universal conversion rule.
- [CSS Text](https://drafts.csswg.org/css-text-4/), [CSS Fonts](https://drafts.csswg.org/css-fonts-4/), [CSS Inline Layout](https://drafts.csswg.org/css-inline-3/) and [CSS UI](https://drafts.csswg.org/css-ui-4/): mechanism references; draft status is distinct from actual browser support.

Measured, derived and judged findings stay separate. Browser checks record their actual engines, device densities and tested conditions. A CSS support query is not a replacement for observed rendering.

Specimen values in the references and examples are author-selected starting points for their context. They are not a new historical movement, a replacement for project branding, or a requirement to install the original article's fonts.

## Avatar-stack research — 2026-10-30

- [Fluent Avatar group usage](https://fluent2.microsoft.design/components/web/react/core/avatargroup/usage): identifies the stack as the condensed overlapping configuration of an avatar group. Its own overflow threshold is a system choice, not the four-slot specimen used here.
- [Primer AvatarStack](https://primer.style/product/components/avatar-stack/): documents a space-constrained inline stack and distinguishes its variants. Its API, hover spread and example assets are not copied into this implementation.

The new rules, diagrams, code and fictional portraits are original. Surface separation, image inset and geometry are explicitly distinct. The D32/O8/G2 study, four-slot capacity and D22 dashboard treatment are author-selected specimens. Image generation prompts and original/derived hashes are preserved in `assets/avatars/`; no model version is invented. Browser measurements, derived extents and visual judgments remain separate.

## CJK and mixed-content row research — 2026-10-30

- [Chinese layout requirements](https://www.w3.org/TR/clreq/), [Japanese layout requirements](https://www.w3.org/TR/jlreq/) and [Korean layout requirements](https://www.w3.org/TR/klreq/): frames/faces, regional glyphs, punctuation and language-specific line breaking.
- [CSS Text 3](https://www.w3.org/TR/css-text-3/) and [CSS Text 4](https://www.w3.org/TR/css-text-4/): wrapping, script spacing and punctuation-space trimming; draft syntax is distinct from engine support.
- [CSS Inline Layout](https://drafts.csswg.org/css-inline-3/), [Flexbox sizing](https://www.w3.org/TR/css-flexbox-1/#cross-sizing), [native table sizing](https://www.w3.org/TR/CSS2/tables.html#height-layout), and [transforms](https://www.w3.org/TR/css-transforms-1/#transform-rendering): separate inline contributions, flex footprints, cell padding and visual offsets.
- [Radix ghost button](https://www.radix-ui.com/themes/docs/components/button#ghost), [MUI IconButton edge](https://mui.com/material-ui/api/icon-button/) and [Chakra Bleed](https://chakra-ui.com/docs/components/bleed): evidence that local negative-margin/padding compensation and controlled extension are established patterns. Their components and code are not copied.

The study uses original rendering code, the existing fictional portraits, and pinned first-party Noto font imports with original OFL notices. Numeric values are specimens, not universal rules. The installed skill retains its own explanation without requiring the article or demo.

The first-party source baseline is `1aron/aron.tw` commit `846333f`; the subsequent figure correction and cross-repository synchronization are recorded in [verification](verification/interface-craft-series-2026-11-02.md). Article typography, book covers and navigation are site-specific examples, not new defaults for consumers.

- [WCAG Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) supports redundant state cues; the examples do not certify a whole interface's conformance.

Common regions, task hierarchy, control mapping and state continuity are first-party design judgments illustrated with controlled examples, without invented user-study metrics. Sources checked 2026-11-02. Original seven-figure sources and asset history remain in the article repository.

## Design guide foundations — 2026-11-12

The new guideline prose is original. [Apple HIG principles](https://developer.apple.com/design/human-interface-guidelines/design-principles) inform task purpose, agency, familiarity and adaptation. [Spectrum inclusive design](https://spectrum.adobe.com/foundations/inclusivity/inclusive-design) informs Web input, content and recovery considerations. [Spectrum token guidance](https://spectrum.adobe.com/page/design-tokens/) informs the separation of semantic decisions from raw values. No platform dimensions, imagery, component APIs or third-party prose are copied.

[WCAG 2.2](https://www.w3.org/TR/WCAG22/) supplies the Web accessibility baseline; [WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/) supplies pattern references, with its documented support limitations. Master UI remains the executable source of its own tokens, contracts and behavior. The guide does not certify every consumer composition.

## Illustrated Web guideline — 2026-11-13

The expanded prose, diagrams, local article fixtures and task examples are original. Sources below inform decisions, not a shared visual style. Site figure labels and implementations stay outside the portable skill; all essential design conclusions remain in canonical reference Markdown.

| --- | --- | --- |
| Purpose, agency, adaptation and craft | [Apple HIG design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles), platform guidance | Evaluate the usefulness and continuity of a task; no Apple materials, imagery, dimensions or platform APIs are imported |
