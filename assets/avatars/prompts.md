# Generated portrait sources

Generated with the built-in image_gen tool on 2026-10-30. The tool did not expose a model version. These are original fictional identities, not downloaded photos or real participants. Interface names and roles are illustrative. The first female portrait was revised at the user's request to Japanese/Korean portrait styling; the earlier unused female image is not a project dependency.

The original PNG files are preserved. The browser assets are resized to 512×512 without crop, exported as WebP quality 95. The circular crop, overlap and edge treatments happen only in the shared HTML/CSS study. See [provenance.json](provenance.json) for paths and hashes.
