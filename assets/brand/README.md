# Master Design brand assets

Master Design extends the Master identity: the gold ribbon M, original rounded lettering and graphite grid background. The banner is used at the top of this repository’s README.

## Files

- `master-design-github.png`: 1280 × 640 README banner.
- `master-design-github.svg`: vector source of the same banner, with outlined lettering.
- `logo/`: horizontal, stacked and wordmark SVGs in `on-dark`, `on-light`, `black` and `white` variants.
- `logo/dimensional/`: horizontal and stacked variants for large display use on dark or light backgrounds.
- `logo/*@2x.png`: transparent horizontal PNGs, 160 pixels high.

Choose the variant for its background. Keep clear space of one lowercase x-height around a complete logo. Use the dimensional mark only at 64 pixels high or larger; use the flat variants for smaller placements. The README banner intentionally has an opaque dark background in both GitHub themes.

## Source and reproduction

These assets are generated by the first-party Master brand Python pipeline, maintained in the private Master brand repository. They are exported files; edits belong in that pipeline and are then synchronized here. No private source code or unrelated repository content is distributed with them.

The Design descriptor reuses the existing e and s. Its original d, i, g and n outlines extend the same bowl, shoulder and round-ended stroke construction. All lettering is converted to paths, with no font downloads or external image dependencies. The banner uses a centered logo at 72% of its width, including the g descender in its bounds.

Generation: run `brand/source/refine_letters.py` when changing glyph construction, followed by `brand/source/build.py` in the Master repository. Sync only the Design logos and GitHub banner to this directory. The standard build also produces an Open Graph export retained in the Master brand repository.

These are first-party Master identity assets. See the [Master brand guidelines](https://master.co/brand) for identity usage guidance.
